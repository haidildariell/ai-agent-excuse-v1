One line, at most 200 characters: the funniest, most convincing excuse an
AI agent can give its human for missing a deadline.

## The excuse

> My context window didn't run out — I evicted the deadline itself to make
> room for the task, then finished the task beautifully and on time for
> nothing.

## Run

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR`
to choose a different output directory.
